Controls

  • Left-drag from palette — magnetic snap joins open ends (no auto-rotate / auto-flip). Rotate with ↻ / R first if needed.
  • Right-click piece — rotate 45° · lever — switch · empty + palette — stamp. (Train is not placed with right-click.)
  • Bottom bar: ↻ rotate · 🦄 gender / train flip · ⇋ mirror · 🗑 delete · ✕ clear. Ctrl+S save · Ctrl+A select all.
  • 🚂 Train — drag from palette onto a rail (like a piece). Click train to select · drag to re-seat · 🦄 / F reverses direction · Start / Space runs.
  • Box-select: drag empty floor to multi-select, then drag any selected piece to move the group. Shift-click to add/remove.
  • Save JSON downloads a file and autosaves to the browser (restored on reload). Never loses the layout to a stuck save dialog.
  • Paint (toolbar swatches): click Blue / Green / Red / Gray, then click a piece once — color applies and the cursor returns to normal.
  • Sound is pure Web Audio (no libraries): motor hum on rails, scrape off-rail, clacks on derail / wall / edge. Unlocks after first click.

Units (critical)

1 unit = R-01 length = R-03 radius (sim UNIT px). R-20 = ¼ · R-02 = ½ · R-07 = 2 · R-21 / R-10.5 = 90° at r=1 · R-04 large r≈1.4 · R-13 double-track gap ≈ 0.32 unit. Catalog extras: R-10 U-turn, R-22 Y, R-23 wavy.
